🔍 Frequently Asked Questions

Is this tool legal and secure?

Yes — this editor works for offline part of the game and adjusts local save values only. It doesn't interfere with online servers or multiplayer features. This is a personal customization tool similar to editing a game config file.

Will it break my game?

Extremely unlikely. The program uses strict value-checks and creates a timestamped backup each time you click save to protect your original state.

I get a Windows Defender warning — why?

No code-signing certificates can be purchased by free projects like ours. That triggers a common detection on unsigned software. You can verify authenticity: compare the SHA-256 hash provided on the Download page once downloaded.

Can I use this same file on Mac or Linux?

Not currently, since you asked for the Windows build. To use it on a Mac or Linux device, you must use a Windows environment or virtual machine. Future releases might cover cross-platform version according to community requests.
